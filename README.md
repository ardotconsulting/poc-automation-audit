# poc-automation-audit

Proof of concept for [How to Audit Your Business Processes for Automation Opportunities](https://www.ardotconsulting.com/blog/2026/10/10/how-to-audit-your-business-processes-for-automation-opportunities/).

Interactive automation audit worksheet: add tasks, score them on frequency, time, and automatability (1–5), see priority scores, and estimate time savings — exactly as described in the blog post.

Static HTML/JS served by `nginx:alpine`. No database, no secrets, no admin.
